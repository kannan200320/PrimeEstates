# PrimeEstates — Luxury Real Estate Web Application

A clean, modern, and professional luxury real estate web application built using **HTML5**, **Tailwind CSS**, and **React JS**.

---

## 🌟 Key Features

### 1. Home Page
- **Hero Sanctuary**: High-impact architectural hero section with quick property search by status (Buy/Rent), location keyword, property type, and price range.
- **Key Metrics**: Institutional stats showcasing sales volume (\$2.4B+), properties transacted, and client satisfaction rates.
- **Featured Properties Showcase**: Filterable categories (Luxury Villas, Skyline Penthouses, Modern Estates) with quick details.
- **Explore by Premier Destinations**: Visual metropolis cards (New York, Los Angeles, Miami, Austin, Seattle, San Diego).
- **The PrimeEstates Standard**: Value propositions with verified legal titles and discreet private representation.
- **Top Advisors Spotlight**: Preview of elite licensed brokers with direct contact access.
- **Verified Client Testimonials**: High-profile client reviews with ratings.
- **Call-to-Action (CTA)**: Direct links to search listings and book private consultations.

### 2. Property Listing Page
- **Comprehensive Search & Multi-tier Filtering**:
  - Keyword and location search (city, state, title, address)
  - Status toggle (`For Sale`, `For Rent`, `All`)
  - Property Type selection (`Villa`, `Penthouse`, `House`, `Apartment`, `Townhouse`, `Studio`)
  - Price Range filter (Minimum and Maximum inputs)
  - Bedroom & Bathroom count selectors
  - Amenities checklist (Swimming Pool, Ocean View, Smart Home, Wine Cellar, Gym, EV Charger, etc.)
  - Sorting options: Featured First, Price (Low to High / High to Low), Most Bedrooms, Largest Area
- **View Toggle**: Grid View and List View options.
- **Interactive Badges**: Live results count, active filter chips with 1-click removal, and "Reset All Filters".

### 3. Property Details Page
- **High-Resolution Photo Gallery**: Large interactive showcase image, thumbnail switcher, and full-screen lightbox modal.
- **Core Property Specifications**: Bedrooms, bathrooms, square footage, garage bays, year built, and lot area.
- **Architectural Narrative**: In-depth description and key residence highlights.
- **Amenities & Inclusions**: Categorized luxury features.
- **Interactive Mortgage Calculator**: Dynamic sliders for home price, down payment percentage, interest rate, and loan term with real-time monthly payment breakdown (Principal & Interest, Property Taxes, Insurance, HOA).
- **Schedule a Private Tour**: Choose between In-Person or Live Video Tour, select dates, preferred time slots, and submit with instant toast feedback.
- **Assigned Real Estate Advisor Box**: Direct phone, email, and instant inquiry messaging form.
- **Neighborhood Mobility Scores**: Walk score, transit score, school district rating, and safety index.
- **Similar / Recommended Properties**: Curated recommendations based on location and property type.

### 4. Agent Directory & Agent Details
- **Agent Directory (`Our Agents`)**: Browse licensed luxury advisors, search by advisor name, and filter by specialty.
- **Agent Profile Detail Page**:
  - Cover photo, headshot, broker license number, verified badge, and rating.
  - Performance statistics: Career sales volume, active listings count, years experience.
  - Full biography, languages spoken, and industry awards.
  - Confidential Advisory Consultation Request form.
  - Active Listings portfolio managed by this advisor.

### 5. Login & Sign Up System
- Sleek modal with seamless tab switching between **Sign In** and **Create Account**.
- Role selector for new registrations (`Buyer`, `Seller`, `Agent`).
- **One-Click Demo Login** shortcut to preview an authentic logged-in VIP profile instantly.
- User profile dropdown in navigation with account details, saved homes link, and logout.

### 6. Contact Page
- **National Advisory Ateliers**: Office locations in New York, Beverly Hills, and Miami Beach.
- **Direct Concierge Info**: Toll-free numbers, encrypted emails, and operating hours.
- **Confidential Inquiry Form**: Dedicated inputs for buying, selling, or private investment advisory with budget ranges.
- **Interactive FAQ Accordion**: Expandable answers to common real estate questions.

### 7. Saved Portfolio / Favorites
- One-click heart icon on any property to save or remove.
- Dedicated **Saved Luxury Properties** page.
- Real-time calculation of total saved portfolio value.

## 🛠️ Technology Stack
- **React 19**
- **Tailwind CSS**
- **HTML5 & CSS3**
- **Vite**
- **Google Fonts** (*Plus Jakarta Sans* & *Playfair Display*)
- **Lucide-Style SVG Icon System** (Zero heavy external icon dependencies)

## 🚀 Running the Project
```bash
# Start development server
npm run dev

# Build for production
npm run build
```
Open `http://localhost:5173` in your browser.
